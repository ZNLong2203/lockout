# Public demo data

Teams, drafts, results and the statistics derived from them, exported by `uv run lockout public-build` and
`uv run lockout public-export` from **Leaguepedia** (https://lol.fandom.com), licensed under
[CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/). These files are shared under the same licence.

Nothing here comes from the licensed GRID data. The hosted demo reads these files in static mode
(`VITE_API=static`); player positions do not exist in public data, so its replays are simulated.
